# Portfolio fonts

Self-hosted WOFF2 Latin subsets of the same Google Fonts families previously requested by `index.html`. The title's normal and italic faces are preloaded to stabilize the loader-to-hero handoff. Other faces load through CSS as needed.

Sources: [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif), [Inter](https://fonts.google.com/specimen/Inter), [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono), [Syne](https://fonts.google.com/specimen/Syne). Downloaded from the Google Fonts CSS API and fonts.gstatic.com on 2026-10-12. Inter and Syne use variable files; the declared weight ranges match the site's existing weights.

All four families use the SIL Open Font License. Original license and copyright notices from the [Google Fonts repository](https://github.com/google/fonts) are included in `licenses/`. The font binaries are unmodified.
